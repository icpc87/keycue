# KeyCue

Soundplant のように、キーボードの各キーに音声・動画・スライド（pptx / key / pdf）を割り当てて流す Mac アプリ。

Windows 版は [windows/](windows/README.md)（C# / WPF。キーマップは共通）。

ライセンスは GPL-3.0-or-later（[LICENSE](LICENSE)・[使っているオープンソース](THIRD_PARTY_NOTICES.md)）。アプリは https://keycue.ic2.jp で配布。

## ビルド

```
./build.sh
open build/KeyCue.app
```

`build/KeyCue.app` ができる（Swift Package、Xcode 不要。macOS 14 以降）。

キーチェーンに「Developer ID Application」の証明書があれば自動でそれで署名する（なければ ad-hoc。`KEYCUE_SIGN_IDENTITY` で指定もできる）。同じ証明書で署名していれば、ビルドし直しても同じアプリとして扱われ、セキュリティソフトや macOS（オートメーション・アクセシビリティ）の許可が続く。

### 配布とアップデート（https://keycue.ic2.jp）

1. `VERSION`（表示用の版、例: 1.1）と `BUILD_NUMBER`（通し番号。必ず増やす）を書き換え、`Website/notes/<版>.txt` にこの版の変更点を 1 行に 1 つ書く。
2. `./release.sh` … Apple Silicon / Intel 両対応でビルドし、Developer ID（Hardened Runtime・時刻認証）で署名、Apple の公証とステープルをして、アップデート用 ZIP と配布用 DMG、サイト一式（`~/Library/Developer/KeyCue/site`）を作る。公証の資格情報は Loopback Mix と同じ `LoopbackApp-notary`。
3. `./deploy_site.sh --dry-run` で確かめてから `./deploy_site.sh` … CORESERVER（`loopbackmix-deploy`）の `/home/ic2/domains/keycue.ic2.jp/public_html` へ、DMG・ZIP → ページ → `version.json` の順に送る。前の版の DMG は `old/` に残る。

アプリは起動時（1 日 1 回）と「KeyCue › アップデートを確認…」で `version.json` を見て、新しい版があればお知らせする。「アップデート」を押すと ZIP をダウンロードし、署名がこのアプリと同じ開発チーム（Team ID）で Apple の公証済みであることを確かめてから、KeyCue を終了して入れ替え、起動し直す。確かめられなければ入れ替えない。アプリが書き込めない場所（ディスクイメージの中など）にあるときはダウンロードページを開く。設定 › 一般 で起動時の確認をやめられる。

### セキュリティソフト（F-Secure の DeepGuard など）

KeyCue は `~/Library/Application Support/KeyCue`（スライドから書き出した画像・動画、多重起動の番号）と `~/Library/Caches/KeyCue` に書き込む。「KeyCue の Library フォルダへのアクセスをブロックしました」と出たら、セキュリティソフトの設定で KeyCue を許可する。止められているとスライドの変換などがエラーになり、下のパネルに「書き込みが止められました」と出る。

## 使い方

- **割り当て**: 音声・動画・画像・スライド（pptx / key / pdf）をキーへドラッグ＆ドロップ。右クリックや下のパネルからも選べる。
  - 複数ファイルを空いたキーに入れると「このキーにまとめる／後ろの空きキーに 1 つずつ」を聞かれる。
  - すでに素材があるキーに入れると「◯ キーにはすでに素材があります」と確認が出て、「後ろに追加」か「差し替える」を選ぶ（設定 › 一般 で「いつも追加」などにもできる）。
- **再生**: キーを押すと再生。もう一度同じキーを押すと設定したフェードアウト時間で止まる（トグル）。別のキーを押すと前の音は止めずに重ねて鳴る。
  - モードは「トグル」「リトリガー（押すたび頭から）」「ホールド（押している間だけ）」から選べる。
  - `ESC` で全停止（フェード）、`Shift+ESC` で即停止、`Shift+キー` でそのキーだけ即停止。
  - 右側の「再生中」には素材ごとにシークバーが出る。クリックかドラッグ（離したところ）で再生位置が変わる。映像付きの素材は映像と音声を同じ位置にそろえて動かす。スライド素材は、いま流している動画・音声素材の中を動かす（画像のときはシークバーなし）。
- **名前の変更**: キーや下のパネルの名前を右クリック →「名前を変更…」（スライド素材の一覧の各素材も同じ）。画面に名前の入力欄は置いていないので、名前を直したあとにキーが文字入力に取られることはない。
- **キーごとの設定**: フェード IN/OUT（秒）、音量、ループ、出力ルーティング、色、映像を出すかどうか、流れ方、映像レイヤー。

## 表示の切り替え（キーボード／グリッド／レイヤー）

設定 › 一般 › 「メイン画面の表示」で、メイン画面を 3 種類から選べる（全インスタンス共通）。キーでの操作はどの表示でも同じ。

### グリッド

素材をサムネイルのカードにして並べる。

- 素材の入っているキーだけを、キーの順（空きキーへ順に入れるときと同じ並び）にカードで並べる。上部のスライダーで大きさを変えられる。
- カード：動画は 1 秒あたりのコマ、画像・スライドはその画像（再生中のスライドは今出ている 1 枚）、音声は波形、ライブ入力はアイコン。左上にキー、下の帯にキーの色と名前。
- 再生中はオレンジの枠と進み具合のバー、スライドは「2/5」のように何枚目かを出す。
- クリックはキーを押したのと同じ（押しているあいだだけ鳴るモードにも対応）。⌘ クリックで選ぶだけ（下に設定が出る）、Shift クリックで即停止、右クリックでキーと同じメニュー。KeyCue が前面でなくても 1 回目のクリックで鳴る。
- カードにファイルをドロップするとそのキーへ、カードの外にドロップすると空いている最初のキーへ入る。
- キーボードでの操作はどちらの表示でも同じ。

### レイヤー

映像の重なり順（映像レイヤー 1〜9、9 がいちばん前）ごとに段を作り、各段にそのレイヤーの素材を並べる。いちばん下は音声だけの素材の段。

- カードを別の段へドラッグすると、そのキーの映像レイヤーが変わる（次に流したときから）。右クリック › 「映像レイヤー」でも変えられる。段にファイルをドロップすると、空いているキーに入ってそのレイヤーになる。
- クリックは離したときに流す（ドラッグと見分けるため。押しているあいだだけ鳴るモードは押した瞬間）。⌘ クリックで選択だけ、Shift クリックで即停止。
- **同じレイヤーは入れ替え**（上部のチェック、または 設定 › 一般。初期値はオン）：カードをクリックしたとき、同じレイヤーで流れている映像を、新しい素材のフェード IN の秒数で消して入れ替える。1 つのレイヤーに 1 つずつ出す使い方になる。キーボードで押したときは、キーの設定どおり。
- 段の左に、そのレイヤーで出ている素材と「止める」ボタン。

## 1 つのキーに複数の素材（押すたび順に切り替え）

Keynote・PowerPoint のように、1 つのキーに素材を順番に入れておき、押すたびに次の素材へ切り替える。

- 作り方: 複数ファイルを 1 つのキーにまとめて入れる／素材のあるキーに「後ろに追加」する／キーを右クリック →「素材を追加…」／素材一覧タブの「＋ 素材を追加…」かファイルのドロップ。
- 音声・動画・画像・pptx / key / pdf を混ぜられる（スライドはスライドごとに展開されて間に入る）。
- キーをダブルクリックすると右横に素材一覧のタブが開き、ドラッグで並び替え、素材ごとの設定、右クリック →「キーから外す」ができる。
- 自分で並べた音声・動画は、終わっても勝手に次へ進まず、キーを押すのを待つ（素材ごとに「終わったら次の素材へ」に変えられる）。最後の素材の次に押すと終了。

## プレイリスト（キーボードのページを丸ごと切り替え）

ProPresenter のプレイリストのように、1 つのプロジェクト（キーマップ）の中にキーボードの「ページ」を並べておき、キーボード全体の素材を即座に入れ替える。例: 1. オープニング → 2. 第一部 → 3. エンディング。

- 左の「プレイリスト」でページをクリックすると、キーボードがそのページの素材に入れ替わる。⌘→ / ⌘← で次・前のページ。
- 鳴っている素材はページを切り替えても止まらない（「再生中」に「ページ 1 で鳴らした素材」と出て、そこから止められる）。切り替えた先のキーは、そのページの素材として鳴る。
- ＋（⇧⌘N）で空のページ、「複製」（⇧⌘D）でいまのページのコピーを次に作る。右クリックで名前の変更・複製・削除、ドラッグで並べ替え。
- キーを右クリック →「ほかのページの同じキーにコピー」で、別のページに同じ素材を置ける。
- 全ページの素材を先に読み込んでおくので、切り替えた瞬間から鳴らせる。
- ページはキーマップに保存される。上部のボタン（いまのページ名）か ⌥⌘L でプレイリストの表示／非表示。

## 流れ方（次の素材が流れたとき）

キーごとに「次の素材が流れたら」を選ぶ。

| 設定 | 動作 |
| --- | --- |
| 重ねて流し続ける（既定） | ほかのキーを押しても止まらず重なる |
| フェードアウトして止める | ほかのキーで新しい素材が始まると、このキーのフェード OUT 秒で止まる |
| すぐ止める | 同じく、フェードなしで止まる |

「対象」をグループ 1〜8 にすると、同じグループのキーが始まったときだけ止まる（グループはキーに「G1」のように表示）。例: BGM をすべてグループ 1・「フェードアウトして止める」にすると、BGM 同士は切り替わり、効果音は上に重なる。

## 映像レイヤー

動画・スライドのキーには「映像レイヤー」（1〜9）がある。数字が大きいほど前面に重なり、同じ数字なら後から流したものが上になる。例: テロップ用の動画を 8、背景映像を 2 にしておくと、どの順で押してもテロップが上に出る。
- **保存**: ⌘S で `.keycue`（JSON）に保存。ファイルは絶対パスとキーマップからの相対パスの両方で記録するので、フォルダごと移しても開ける。インスタンスごとに前回のキーマップを次の起動で開き直す。

## 出力ルーティング（どのラインから出すか）

上部の出力デバイスでオーディオインターフェースを選ぶと、その全チャンネルを使う。キーごとの「出力ルーティング…」で、元の音声チャンネル（行）× 出力チャンネル（列）の表が開く。マスをクリックしてつなぐ／外す。1 つの元チャンネルを複数の出力へ送ることもできる。

- 列の上の **M** はその出力のミュート、**T** は 1kHz のテストトーン（マスター音量に従う）。どちらも全キー共通で、M はキーマップに保存される。右側のメーターの番号をクリックしてもミュートできる。
- 「まとめて指定」に `3`（3ch から順に）、`1,2`、`5-8` のように書いて「適用」でも設定できる。
- 「自動に戻す」で既定（モノラル → 1,2 / ステレオ → 1,2 / 8ch → 1〜8）に戻る。「全キーに適用」でこのキーの設定をほかのキーへコピーする。

右側のメーターは「素材」と「出力」を切り替えられる（既定は素材）。

- **素材**: 選んでいるキー（なければ最後に鳴らしたキー）の素材を、素材のチャンネルごとに表示する（4 トラックの mov なら 4 本、ステレオなら L/R）。各バーの下にその ch の出力先（→1、→1,2 など。括弧付きはいまのデバイスにない ch）が出る。音量・フェード後、マスター前のレベル。「再生中」の各行にも小さな素材メーターが出る。
- **出力**: 出力チャンネルごとのレベル。番号クリックでミュート。

出力メーターとルーティング表は、出力デバイスが 2ch でも常に 8ch 分出る。デバイスにない ch（暗い表示）につないだ音は鳴らないがメーターには出るので、本番の多 ch インターフェースがなくても出し分けを確かめられる。

**複数の音声トラックを持つファイル**（例: モノラルトラック 4 本の mov）は、トラック 1 → ch1、トラック 2 → ch2 … と並べて 1 つの多チャンネル音源として扱う。出力デバイスの ch 数が足りないと自動ルーティングでは 1,2 に折り返されるので、4ch 以上のインターフェースを選ぶか、ルーティング表で出し先を決める。

## スライド素材（pptx / key / pdf）

pptx・key・pdf をキーに入れると、スライドごとの PNG と、スライドに埋め込まれた動画・音声に展開して「素材リスト」を作る。

- **変換に使うアプリ**: pptx・ppt は PowerPoint（入っていなければ自動で Keynote）、key は Keynote。pdf はそのまま各ページを PNG にする。初回だけ十数秒かかり、結果は `~/Library/Application Support/KeyCue/Decks/` に保存されて次からはすぐ開く。元ファイルを更新すると自動で作り直す。
- 初めて変換するとき、macOS が「KeyCue が PowerPoint（Keynote）を操作しようとしています」と確認するので許可する。拒否した場合は システム設定 › プライバシーとセキュリティ › オートメーション で許可できる。変換中は PowerPoint / Keynote が一時的に起動する（KeyCue が起動した場合は終わったら閉じる。元のファイルは保存しない）。
- **素材一覧タブ**: キーをダブルクリック（または下のパネルの「素材一覧を開く」）で右横にタブが開く。複数のキーを開くとタブが並ぶ。
  - 素材が再生順に並ぶ。ドラッグで並び替え、行をダブルクリックか ▶ でそこから再生。
  - 行を選ぶと下に設定が出る：名前、流す／飛ばす、画像は「次へ」（キーの設定に従う／キーを押すまで待つ／秒数で自動）、動画・音声は音量と「終わったら」（次の素材へ進む／最後で止まって待つ／ループ）、「この素材に入るとき」の切り替え（おまかせ／なし／ディゾルブ／黒を経由してフェード／白を経由してフェード と秒数）、「止めるときのフェードアウト」の秒数。
  - 上部で、画像を自動で送るか（何秒ごと）、切替の効果と秒数（素材ごとに決めていない素材に使う）、最後の次は先頭へ戻るかを設定する。
- **切り替え効果（フェード）**: PowerPoint・Keynote のフェードに相当する切り替えを使える。
  - ディゾルブ：前の素材と重ねながら入れ替える（PowerPoint の「フェード（スムーズ）」、Keynote の「ディゾルブ」）。
  - 黒／白を経由してフェード：いったんその色にしてから次の素材を出す（PowerPoint の「フェード（黒）」、Keynote の「カラーでフェード」）。音も前半で消え、後半で入る。
  - なし：すぐ切り替える。
  - キーを押してその素材から始まるときも、素材ごとに選んだ効果で出る（おまかせなら、キーのフェード IN）。
  - pptx・key に付けてある画面切り替えは、変換時に読み取って「おまかせ」の中身になる（フェードはそのまま、ほかの効果はディゾルブで近づける）。素材ごとに選べばそちらが優先。前のバージョンで変換したスライドは「変換し直す」で読み取る。
  - ⋯ メニューから、書き出したフォルダを Finder で開く、並びと設定を元に戻す、変換し直す。
- **再生**: キーを押すと最初の素材から流れ、押すたび次の素材へ。最後の次で終了（「最後の次は先頭へ」なら繰り返し）。Shift+キーで即停止。右側の「再生中」やタブの ◀ ▶ でも前後に動かせる。
- 非表示（スキップ）にしているスライドも一覧に入るが「飛ばす」になっている。必要なら「流す」に変える。
- 動画・音声素材の音は、そのキーの出力ルーティング・音量で鳴る。
- スライド内のアニメーションは再現されない（各スライドを 1 枚の画像にする）。画面切り替えはフェード系に置き換えて再現する。

## 動画

- 動画・スライドを割り当てたキーを押すと「映像出力」に表示される。
- **出すモニター（複数可）**: 上部の「映像: …」メニューか 設定 › スクリーン で、ウィンドウと各ディスプレイ（全画面）を何か所でも選べる。選んだ出力すべてに同じ映像が出る。全画面は選んだモニターを覆い、キー入力はメインウィンドウに残る。「画面を識別」で各ディスプレイに番号が出る。つないでいないディスプレイを選んでおくと、つないだときに自動で出る。
- **キーごとの出す画面**: キーの設定の「出す画面」で、そのキーの映像を出す出力を絞れる（例: テロップはウィンドウだけ、本編は全ディスプレイ）。
- 下のパネルで割り当てた動画をプレビュー（ミュート・スクラブ可）、右側の「映像モニター」で出力中の映像をアプリ内でも見られる。
- 動画の音声はオーディオエンジン側で鳴らすので、多チャンネル出力・フェードが音声ファイルと同じように効く。映像は出力デバイスの時計に同期させている。
- 音声をメモリに展開するため、1.5GB を超えるような長尺動画の音声は映像プレーヤーから出す（この場合 ch 指定は効かない）。
- **透明部分のある動画（テロップなど）**: ProRes 4444・HEVC（アルファ付き）はそのまま、透明部分が下のレイヤーに重なって出る。いまの macOS で再生できない QuickTime の「アニメーション」形式（RGB＋アルファ）は、入れたときに透明部分を残したまま ProRes 4444 に変換して使う（初回のみ・数秒。変換したものは `~/Library/Application Support/KeyCue/Converted/` に置き、元のファイルを更新すると作り直す）。

## ライブ入力（Web カメラ・キャプチャ機器・オーディオ入力）

- キーを右クリック › 「ライブ入力（カメラ・キャプチャ・音声入力）を割り当て…」、下のパネルの「ライブ入力を割り当て…」、またはメニュー「ファイル › 選択中のキーにライブ入力を割り当て…」で、映像入力と音声入力を選ぶ（片方だけでもよい）。
- 映像は Mac が認識しているカメラすべてが選べる：内蔵カメラ、USB の Web カメラ、UVC 対応やドライバー入りのキャプチャ機器（HDMI キャプチャなど）、iPhone の連係カメラ、OBS の仮想カメラなど。音声はマイク、オーディオインターフェース、キャプチャ機器の音声、Loopback などの仮想デバイス。
- キーを押すと入力が映像出力・音声出力に出て、もう一度押すとフェードして止まる。フェード、音量、出力ルーティング、映像レイヤー、出す画面、次の素材が流れたときの動きは、ファイルと同じように効く。
- 音は 30ms ほどためてから出し、入力と出力の時計のずれで遅れがたまらないよう 150ms を超えたら詰める。
- 同じカメラを複数のキーや画面で使っても、キャプチャは 1 つにまとめる（負荷が増えない）。
- 初めて使うときに、カメラ・マイクの使用許可を求めるダイアログが出る。断った場合は システム設定 › プライバシーとセキュリティ › カメラ／マイク で KeyCue を ON にする。
- 割り当てた機器がつながっていないと、キーの情報欄に「つながっていません」と出る。つなぎ直せばそのまま使える。

## 多重起動

メニュー「KeyCue › 新しいインスタンスを起動」（⌥⌘N）、または `open -n build/KeyCue.app`。インスタンスごとに番号（#1, #2…）が付き、出力デバイス・キーマップ・映像出力先・ウィンドウ位置を別々に持てる。

キーは前面にあるインスタンスにだけ届く。設定 › 一般 の「バックグラウンド入力」を ON にすると、他のアプリが前面のときもキーで鳴る（アクセシビリティの許可が必要）。

## 設定（⌘, または上部の「設定」）

| タブ | 内容 |
| --- | --- |
| 映像 | 映像出力の開閉、起動時に映像出力を開く、縦横比が違うときの映り方（全体／いっぱい／引き伸ばし）、背景色 |
| スクリーン | 映像を出すモニターの選択（ウィンドウと各ディスプレイ・複数可）、画面の識別、つながっていないディスプレイの表示 |
| 音 | 出力デバイス、マスター音量、全停止のフェード、出力 ch ごとのミュート・テストトーン、新しく入れるキーの初期値（モード・フェード IN/OUT・次の素材が流れたら） |
| 一般 | キーボード配列（自動／US／JIS・次の起動から）、バックグラウンド入力、すでに素材があるキーに入れたとき・複数ファイルを入れたときの動き、pptx の変換アプリ、起動時に前回のキーマップを開く、書き出した素材のフォルダ、新しいインスタンス |

出力デバイス・マスター・ミュート・映像を出すモニターはインスタンスごと（キーマップに保存）、それ以外は全インスタンス共通。

## メモ

- F1〜F12 は Mac の設定によっては明るさ・音量キーとして扱われる。キーマップで使うときは fn を押しながら押すか、システム設定 › キーボード で「F1、F2 などのキーを標準のファンクションキーとして使用」を ON にする。
- キーボード配列（US / JIS）は接続中のキーボードから自動で切り替わる。
- フェード秒数などの数値の入力欄にカーソルがあるあいだは、キーは文字として入り再生・停止しない（下のステータスに案内が出る）。Enter で確定するか、キーボードの図をクリックすると戻る。

## 開発用の自動チェック

```
KEYCUE_SELFTEST=<素材フォルダ> build/KeyCue.app/Contents/MacOS/KeyCue
```

素材フォルダに `eight_ch.wav`（8ch）, `stereo_44k.wav`, `mono.wav`, `clip.mp4`（音声付き動画）, `four_tracks.mov`（モノラル 4 トラック）, `deck.pptx`（4 枚・2 枚目に動画・3 枚目が非表示）を置くと、読み込み・ルーティング・ミュート・重ね再生・次の素材でのフェード停止とグループ・映像レイヤー順・スライド素材の展開と送り・並び替え・素材ごとの自動送りを確認して終了する（マスター音量は小さくして鳴らす）。`KEYCUE_SELFTEST_DECK=deck.key` や `=slides.pdf` で別の形式も確認できる。
